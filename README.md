# MonSiteWeb

Site vitrine d'apprentissage réalisé avec HTML et CSS, versionné avec Git et publié sur GitHub.

## Contenu

- Page d'accueil avec les sections À propos, Services, Témoignages, Équipe et Contact
- Feuille de style `style.css`

## Utilisation

Ouvrir le fichier `index.html` dans un navigateur.
